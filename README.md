# Molecular-docking-of-natural-phytochemicals-against-JAK-proteins.
This thesis revolves around the idea of inhibiting JAK/STAT proteins in inflammatory diseases such as Atopic Dermatitis where, this pathway plays a crucial role. I have used bioinformatic tools and software for ADMET analysis (Swiss ADME), virtual screening (PyRx, BIOVIA Studio), Molecular Docking (UCSF Chimera, AutoDock Vina) and Molecular Dynamic Simulation (GROMACS, Desmond). 
14 natural compounds were screened against JAK1,2 and 3 proteins using the bioinformatic tools mentioned. 
Out of the 14, Verbacoside, Diosmetin and Hecogenin emerged to be possible JAK inhibitors showing Pan-JAK activity.
